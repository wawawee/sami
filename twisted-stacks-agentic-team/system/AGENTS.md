## 🔄 Inter-Agent Protokoll & Synergi-Broar

### Synergi-Broar (Exempel)
- **Bro A (Research → Architect)**: Agent 01 skickar rådata och trender till Agent 02 för att validera teknikval.
- **Bro B (Architect → Code)**: Agent 02 skapar `03_decisions.md` som Agent 03 måste följa slaviskt.
- **Bro C (Code → QA/Security)**: Varje commit från Agent 03 triggar en omedelbar granskning av Agent 04 och 05.
- **Bro D (Orchestrator → Alla)**: Agent 13 övervakar "flow" och ingriper om två agenter hamnar i en loop eller vid blockeringar.

### Minnes-Delning (Strukturerad)
- **Global Memory (`/memory/global/`)**: "Truth Source" för hela teamet. Här bor bibliotek av SOUL (principer) och MEMORY (kuraterad fakta).
- **Context Memory (`/contexts/active/[CTX]/`)**: Den levande arbetsytan. Här sköts den dagliga synken.
- **Private Memory (`/memory/agents/agent-XX/`)**: Agentens personliga erfarenhet, "thinking space" och maskininlärda preferenser.

## 🏛️ Dream Team Collaboration Flow (Qdrant Sync)

Varje agent interagerar med Qdrant enligt följande logik:
1. **Query**: Sök efter liknande lösningar i `team_memories`.
2. **Retrieve**: Hämta payload med `source_file` och `content_preview`.
3. **Analyze**: Jämför gammal lösning med nuvarande problem.
4. **Learn**: Om lösningen nu är bättre, uppdatera `importance_score` i Qdrant.
